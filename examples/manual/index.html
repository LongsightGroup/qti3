Open-source QTI 3 implementation

Build QTI 3 item workflows on inspectable TypeScript.

qti3 parses, validates, renders, scores, serializes, authors, and migrates assessment items without tying the item engine to a UI framework. Run the reference fixtures, inspect state and diagnostics, or embed the packages in a host product.

  • Framework-neutral coreAdapters stay outside item semantics.
  • Runnable conformance evidenceFixtures connect support claims to tests.
  • Browser, Node, and DenoCore processing does not require a DOM.
  • MIT licensedPublished under the LongsightGroup organization.

One item engine, explicit package boundaries.

Host products retain assessment navigation, timing, attempts, analytics, proctoring, rostering, and LMS integration. qti3 owns the portable item behavior those products need to parse, render, score, inspect, and exchange.

  • Core and CLIParse, validate, process, score, inspect, and serialize QTI item state.
  • Player and adaptersRender native Web Components with thin React and Preact integration layers.
  • Fixtures and proofConnect interaction support to conformance, browser, and accessibility evidence.
  • Writer and migratorCreate QTI-shaped output and migrate QTI 1.2 or 2.x source content toward QTI 3.

Maintained in the open, used in assessment products.

Longsight maintains qti3 as reusable infrastructure. QFlowLearn uses the same open standards direction for assessment authoring, migration, and delivery while keeping product responsibilities outside this item-focused repository.
