# qti3

## Register

product

## Users

Assessment-platform engineers, item-authoring teams, standards implementers, and accessibility reviewers use qti3 while integrating, validating, rendering, scoring, or migrating QTI 3 assessment items. They need to inspect actual behavior, run examples, understand package boundaries, and find evidence for supported interactions without interpreting promotional claims.

## Product Purpose

qti3 is a dependency-light, framework-neutral TypeScript reference implementation for QTI 3 assessment items. It provides auditable packages for parsing, validation, response processing, scoring, browser rendering, accessibility, fixtures, conformance, PNP resolution, authoring output, and migration. The public manual should help developers evaluate the implementation, test interactions, select packages, and reach the source and supporting documentation quickly.

## Brand Personality

Precise, inspectable, and practical. The interface should feel like a maintained engineering instrument: clear enough for first-time evaluators, dense enough for implementers, and careful about the line between demonstrated behavior and standards certification.

## Anti-references

- A glossy SaaS landing page that hides technical boundaries behind marketing claims.
- A terminal-themed developer site that uses monospace styling as a substitute for information design.
- A component gallery with attractive screenshots but no runnable behavior or evidence.
- Heavy documentation frameworks that obscure the dependency-light character of the project.

## Design Principles

1. Put runnable evidence next to each claim.
2. Preserve the manual as a working engineering tool, not a static brochure.
3. Make package and host-product boundaries explicit.
4. Help new readers orient without slowing down experienced implementers.
5. Prefer direct language, stable URLs, and inspectable source.

## Accessibility & Inclusion

Target WCAG 2.2 AA. Preserve semantic landmarks, sequential headings, keyboard access, visible focus, 200% zoom and narrow reflow, forced-colors behavior, reduced-motion preferences, and sufficient contrast. The manual must remain usable while exercising complex QTI interactions.
